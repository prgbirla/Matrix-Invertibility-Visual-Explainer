# Matrix-Invertibility-Visual-Explainer
An interactive visual explainer of matrix transformations, determinants, and invertibility.

This project was inspired by https://yizhe-ang.github.io/matrix-explorable/
This project was assigned by Prof. Kieran Murphy at NJIT

See Releases section for code and versions.

This project started with a draft text for the explainer. A simple prompt to ChatGPT led to Version 1. Attempts at revision there did not improve the project.
I then used the same prompt on Gemini. The visuals for this Version 2 were inadequate and almost disconnected from the text. I re-made the prompt to have more specifications for the visual portion. This was Version 3.

Version 3 was much stronger in terms of visuals, however, it struggled in displaying mathematical notation. I used online sources to find ways to use MathJax to display the correct notation. This led to Version 3.4, which is a technically correct explainer in terms of code. However, I felt that the text that Gemini had created from my text was too minimal and hard to understand for a beginner to linear algebra (which is the target audience for this project). I made edits to the text, using much of my original script and some of Gemini's text. The result is Version 4, the final product.

I hope this serves as a guide to the basics of creating websites using visuals and text, and using agents, online resources, and human logic.
To the learners: Have fun exploring!
